      Marcar meus jogos

      Importar da Epic Games Lê a biblioteca que o Epic Games Launcher guarda no seu PC (Windows). O arquivo é lido aqui no navegador e não é enviado para lugar nenhum.
      Como achar o arquivo
      1. Clique em Escolher arquivo. O caminho do arquivo é copiado e a janela de abrir arquivo aparece.
      2. Clique no campo Nome da janela, cole com Ctrl+V e aperte Enter.
      3. Se não colar, digite o caminho:
        C:\ProgramData\Epic\EpicGamesLauncher\Data\Catalog\catcache.bin

      A pasta ProgramData é oculta no Windows, por isso é mais fácil colar o caminho do que procurar. Abra o Epic Games Launcher pelo menos uma vez antes, para o arquivo estar atualizado.
